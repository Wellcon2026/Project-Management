# ราคากลาง (Price Book) — คำตอบผู้บริหาร (บันทึก 19/11/2026 · ผู้บริหารสั่ง "Agree please proceed" 19/11/2026 → ทำระยะ 1 แล้ว)

## ตอบเรื่องที่ต้องระวัง 4 ข้อ
1. **รวมเป็นชุดเดียว** — ยกระดับ "อัตรากลาง" เดิมเป็น "ราคากลาง" · ข้อมูลต้นฉบับชุดเดียว ทุกคน / ทุกระบบใช้ร่วมกัน
2. **ราคากลาง = ฐานเริ่มต้นการคุย ไม่บังคับใช้ราคาสัญญาก่อน** — เงื่อนไขงานต่างกัน (ขนาดพื้นที่ · ระยะเวลา · ความยากง่าย) ผู้รับเหมาคิดเพิ่มได้ แต่การเริ่มคุยต้องอิงราคาพื้นฐานเดิมก่อน
   → ต้องแก้ข้อ 2.2 ใน docs/pricing-principles.md (ลำดับที่มาของราคา) + บันทึกในประวัติการตัดสินใจ เมื่อเริ่มทำ
3. **ราคาเปลี่ยนตามเวลา** (ราคา 5 ปีก่อนต่างจากวันนี้) — การเปลี่ยนราคากลางต้องผ่านการอนุมัติของ QS · Director · Admin ก่อนใช้
4. **นำเข้า Excel ไม่ทับข้อมูลทันที** — แสดงสิ่งที่จะเปลี่ยนก่อน → อนุมัติ → เผยแพร่ · ใบเสนอราคาเก่าคงราคาเดิม

## ยังรอคำตอบ (ระยะ 1 ใช้ค่าที่แนะนำไปก่อน)
- ข้อ 3: ต้องอนุมัติครบทั้ง 3 ตำแหน่งตามลำดับ (QS → Director → Admin) หรือคนใดคนหนึ่งก็ได้
- ข้อ 2: เวลาปรับราคาจากฐาน (เช่น +15% เพราะงานยาก) ต้องใส่เหตุผลไหม / ปรับเกินกี่ % ต้องอนุมัติเพิ่ม
- ราคาต่างตามประเภทงาน (โรงแรม / บ้านพัก / ร้านอาหาร) หรือใช้ตัวคูณตามโครงการ
- ช่องทางด่วน: วงเงิน และผู้อนุมัติ
- ใส่คอลัมน์ต้นทุนตั้งแต่ระยะ 1 ไหม

## ค่าที่ใช้ในระยะ 1 (ผู้บริหารให้ใช้ค่าที่แนะนำ)
- อนุมัติครบ 3 ขั้นตามลำดับ: QS (QS / QS Manager) → Director → Admin (Super Admin) · ผู้ขอเป็น QS = ขั้น QS ผ่านอัตโนมัติ · ไม่มี Director ที่ใช้งาน → Super Admin อนุมัติแทนได้
- ปรับราคาจากฐาน: ไม่บังคับเหตุผล / ไม่จำกัด % — ระบบแสดง "ราคากลาง ±x%" ให้ผู้อนุมัติเห็นทุกบรรทัด
- ราคาเดียวทุกประเภทงาน (ตัวคูณตามโครงการ = ระยะถัดไป)
- ช่องทางด่วน + คิวงาน QS = ระยะ 2 · คอลัมน์ต้นทุน = ระยะ 3
