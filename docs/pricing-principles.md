## 2. หลักที่ทุกแผนกใช้ร่วมกัน

### 2.1 ราคามี 2 ชั้น — ห้ามปนกัน
- **ราคาขาย** = ราคาที่ลูกค้าเห็น: ราคากลาง (app_state `priceBook` · ฉบับเผยแพร่เขียนลง `claimRates` ให้ทุกแอปอ่าน) · ราคาตาม BOQ สัญญา (app_state `projRefBoq`) · ใบเสนอราคา (app_state `quotations`) · VO Tracker (ตาราง `additional_work` ช่อง `rate`)
- **ต้นทุน** = เห็นเฉพาะคนใน (ตำแหน่งที่มีสิทธิ์ตัวเลขเงิน): BOQ จัดซื้อ (ตาราง `boq` ราคาซื้อ / ผู้ขาย) · ใบขอซื้อ / ใบขอจ้าง · PO (Mango) · ราคาผู้รับเหมาใน VO Tracker (`ctrRate`)
- **ห้ามนำต้นทุน กำไร หรือชื่อผู้รับเหมาไปใส่เอกสารลูกค้า** (ใบเสนอราคา · หนังสือเคลม · ข้อความ whatsnew) — ใบเสนอราคาลูกค้ารวม OH&P ไว้ในราคา / หน่วยเป็นค่าเริ่มต้น
- ทุกเอกสารราคาควรมีทั้งสองชั้น ระบบถึงจะคำนวณกำไรได้

### 2.2 ลำดับที่มาของราคา
(แก้ 19/11/2026 ตามคำตอบผู้บริหาร — เดิมบังคับราคาสัญญาก่อน)
1. **ราคากลางของบริษัท** (การ์ด "ราคากลาง" · ข้อมูลต้นฉบับชุดเดียว ทุกคน / ทุกระบบใช้ร่วมกัน) = **ฐานเริ่มต้นการคุยราคา**
   - ปรับขึ้น / ลงได้ตามเงื่อนไขงาน (ขนาดพื้นที่ · ระยะเวลา · ความยากง่าย) — ผู้รับเหมาคิดเพิ่มได้ แต่ต้องเริ่มคุยจากราคากลางก่อน
   - Quotation Maker เก็บราคาฐานไว้ในรายการ และแสดง "ราคากลาง ±x%" ให้ผู้อนุมัติเห็นทุกบรรทัดที่ปรับ
2. **ราคาในสัญญา** (BOQ สัญญาของโครงการ) — ใช้กับงานลด (หักตามราคาสัญญา) และใช้เทียบ ไม่บังคับเป็นราคางานเพิ่ม
3. **QS ประเมินเอง** — รายการที่ไม่มีในราคากลาง ต้องเขียนที่มาของตัวเลข และผู้อนุมัติต้องเห็นว่ารายการไหนกรอกเอง

### 2.2.1 การเปลี่ยนราคากลาง
- ราคาเปลี่ยนตามเวลา → แก้ / นำเข้า Excel แล้ว **ส่งคำขอ** ต้องผ่าน **QS → Director → Admin** ตามลำดับก่อนเผยแพร่ (ผู้ขอเป็น QS = ขั้น QS ผ่านอัตโนมัติ)
- นำเข้า Excel ไม่ทับข้อมูลทันที — แสดงรายการใหม่ / แก้ / เลิกใช้ / ราคาเปลี่ยน ≥ 20% ก่อน
- เผยแพร่ = ฉบับใหม่ + วันที่มีผล · เก็บประวัติ 20 ฉบับ · ใบเสนอราคาเก่าคงราคาเดิม (ราคาอยู่ในใบแล้ว)
- ระยะ 1 ยังไม่มีคอลัมน์ต้นทุน (ราคาขายเท่านั้น) · ระยะ 2 = ช่องทางด่วน + คิวงาน QS + ผูกรหัสกับ Take-off · ระยะ 3 = ต้นทุนอ้างอิง + ตรวจกำไร

### 2.3 ใบเสนอราคาให้ลูกค้าออกที่เดียว
- **Quotation Maker** คือที่เดียวที่ออกใบเสนอราคาให้ลูกค้า (มีขั้นอนุมัติ · เอกสาร DRAFT จนกว่าจะอนุมัติ · อนุมัติใบของตัวเองไม่ได้)
- Claim = ลงทะเบียนเรื่อง + เรียกเก็บค่าเสียหายจากผู้ทำ · ถ้าลูกค้าจะจ้างเราซ่อมเอง → ส่งต่อไป Quotation Maker
- VO Tracker = ติดตามงานเพิ่มจนเข้าสัญญา (ยื่นแล้ว → ลูกค้าอนุมัติ → ออก VO เข้าสัญญา)
- หน้า VO / SI / EOT (ตัวคำนวณ) และฟอร์ม "ใบเสนอราคางานเพิ่ม-ลด" ในหน้าออกหนังสือ **ปิดทั้งระบบ — ไม่ใช้ทำราคาแล้ว**
- งานใหญ่ / ประมูลทั้งโครงการ ทำ BOQ ใน Excel กับฝ่ายประมาณราคา (Quotation Maker ออกแบบมาสำหรับงานไม่ซับซ้อน)

### 2.4 กติกาบริษัทที่ระบบบังคับ
- No Signature = No Production · No Signed VO = No Additional Work · No Approved BOQ = No PO · No Approved PO = No Payment
- แจ้ง VO ภายใน 48 ชม. นับจากได้รับคำสั่ง (Quotation Maker งานเปลี่ยนแบบนับถอยหลังให้)
- ราคาเป็นบาท ระบุ "รวม VAT" / "ไม่รวม VAT" ทุกครั้ง · VAT 7%

## 5. จุดที่ยังต้องพัฒนา (เรียงตามผลกระทบ)
1. **งบโครงการใช้ราคาขายเป็นงบรายจ่าย** — หน้าโครงการคิด "งบ = มูลค่าสัญญา + VO" แล้วเทียบยอดซื้อ ใช้ถึง 100% = กำไรศูนย์โดยไม่เตือน → ควรใช้งบต้นทุน = ราคาขาย × (1 − กำไรเป้าหมาย) และเตือนเมื่อใช้ 80%
2. **ไม่มีจุดตรวจกำไรตอนเสนอราคา** — Quotation Maker คิดแต่ราคาขาย · ช่องต้นทุนผู้รับเหมาใน VO Tracker ยังไม่มีใครกรอก (0 / 5 รายการ) · BOQ จัดซื้อยังไม่มีราคา (0 / 12 แถว) → ควรมีแผงต้นทุนภายใน (QS Manager / ผู้บริหาร) แสดง % กำไร + เตือนเมื่อต่ำกว่าเกณฑ์
3. ~~งานเพิ่มในโครงการยังไม่ใช้ราคาสัญญาก่อน~~ — ผู้บริหารตัดสิน 19/11/2026: ใช้ราคากลางเป็นฐาน ปรับตามเงื่อนไขงานได้ (ไม่บังคับราคาสัญญา)
4. **% ค่าดำเนินการ / กำไรคนละมาตรฐาน** — อัตรากลาง OH&P 15% · Quotation Maker 10–15% + Preliminary 8–20% · Claim ไม่มี Preliminary / OH&P ตั้งรายเรื่อง → ควรมีตารางนโยบายเดียวตามประเภทเอกสาร
5. **อนุมัติไม่ผูกวงเงินและกำไร**
6. **หลังลูกค้าอนุมัติ ข้อมูลไม่ไหลต่อ** — ใบขอซื้อ / ใบขอจ้างไม่อ้างเลข VO · งวดเบิกปิดทั้งระบบ
7. ~~อัตรากลางไม่มีรอบทบทวน / วันที่มีผล~~ — ราคากลางมีวันที่มีผล / วันทบทวน / แหล่งที่มาแล้ว (19/11/2026) · ยังไม่ป้อนกลับจากต้นทุนจริง (ระยะ 3)
8. **ปริมาณจาก Takeoff · วัดหน้างาน ยังไม่ไหลเข้า Quotation Maker**

- กำไรเป้าหมายที่ใช้ตั้งงบต้นทุน · วงเงินอนุมัติแต่ละระดับ · % Preliminary / OH&P ตามประเภทเอกสาร · ใครเห็นต้นทุนได้บ้าง

## 6. ก่อนแก้อะไรที่เกี่ยวกับราคา — ตรวจ 5 ข้อ
1. เปลี่ยนนี้ทำให้ต้นทุน / กำไร / ชื่อผู้รับเหมาไปโผล่ในเอกสารลูกค้าหรือไม่
2. ยังเคารพลำดับที่มาของราคา (ราคากลางเป็นฐาน แสดง % ที่ปรับ → ประเมินพร้อมที่มา · งานลดใช้ราคาสัญญา) หรือไม่
3. ใบเสนอราคาลูกค้ายังออกที่ Quotation Maker ที่เดียว และยังผ่านขั้นอนุมัติหรือไม่
4. กระทบใบเก่าที่อนุมัติ / ส่งลูกค้าไปแล้วหรือไม่ (ห้ามเปลี่ยนตัวเลขย้อนหลัง — ให้ทำฉบับแก้ไข Rev.)
5. แจ้งผู้ใช้ (whatsnew) และบันทึกเหตุผลในส่วนประวัติการตัดสินใจแล้วหรือยัง
