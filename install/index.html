ติดตั้งครั้งเดียว ใช้งานเหมือนแอปทั่วไป — เปิดจากไอคอนบนหน้าจอได้เลย อัปเดตเองอัตโนมัติ ไม่ต้องโหลดจาก App Store / Play Store

ไปที่รายการแอป ↓
⚠️ ตอนนี้เปิดอยู่ในแอป LINE / Facebook — ติดตั้งจากตรงนี้ไม่ได้ กดปุ่ม ⋮ หรือ แชร์ มุมขวา → เลือก “เปิดในเบราว์เซอร์” / “Open in Safari / Chrome” แล้วทำตามขั้นตอนด้านล่าง

วิธีติดตั้ง

เลือกอุปกรณ์ของคุณ (ระบบเลือกให้อัตโนมัติแล้ว) — ทำซ้ำกับทุกแอปที่ต้องใช้

  1. เปิดลิงก์แอปด้วย Google Chrome หรือ Microsoft Edgeกดปุ่ม “เปิดและติดตั้ง” ของแอปที่ต้องการด้านล่าง
  2. กดไอคอนติดตั้ง ⊕ / 🖥↓ ท้ายช่องที่อยู่เว็บถ้าไม่เห็นไอคอน — Chrome: ⋮ → แคสต์ บันทึก และแชร์ → ติดตั้ง… · Edge: ⋯ → แอป → ติดตั้งไซต์นี้เป็นแอป
  3. กด “ติดตั้ง”แอปจะเปิดเป็นหน้าต่างของตัวเอง และมีไอคอนใน Start Menu / Desktop — คลิกขวาที่ไอคอนบน Taskbar → ปักหมุด เพื่อเปิดได้เร็ว

Mac ใช้ Chrome / Edge ได้เหมือนกัน · Safari บน Mac: เมนู ไฟล์ → เพิ่มไปยัง Dock

  1. เปิดลิงก์ด้วย Chromeสแกน QR ด้วยกล้อง หรือกดลิงก์ — ถ้าเปิดจาก LINE ให้กด ⋮ → เปิดในเบราว์เซอร์ ก่อน
  2. กด ⋮ มุมขวาบน → ติดตั้งแอปบางรุ่นจะเขียนว่า เพิ่มลงในหน้าจอหลัก หรือมีแถบ “ติดตั้ง” เด้งขึ้นมาด้านล่างเอง
  3. กด “ติดตั้ง”ไอคอนแอปจะอยู่บนหน้าจอหลัก / ลิ้นชักแอป เหมือนแอปทั่วไป
  1. เปิดลิงก์ด้วย Safariสแกน QR ด้วยกล้อง iPhone แล้วแตะลิงก์ที่ขึ้นมา — ถ้าเปิดจาก LINE ให้กด แชร์ → เปิดใน Safari ก่อน
  2. แตะปุ่มแชร์ ⬆︎ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)อยู่แถบล่าง (iPhone) หรือแถบบน (iPad) — ถ้าไม่เห็น ให้แตะ ⋯ ก่อน
  3. เลื่อนลง แตะ เพิ่มไปยังหน้าจอโฮม → เพิ่มถ้ามีตัวเลือก “เปิดเป็นเว็บแอป” ให้เปิดไว้ — ไอคอนจะอยู่บนหน้าจอโฮม

ปัญหาที่พบบ่อย

ไม่เห็นปุ่ม “ติดตั้ง”
  • ต้องใช้ Chrome / Edge (คอมพิวเตอร์, Android) หรือ Safari (iPhone) — เปิดจากใน LINE / Facebook ติดตั้งไม่ได้
  • โหมดไม่ระบุตัวตน (Incognito) ติดตั้งไม่ได้
  • ถ้าเมนูขึ้นว่า “เปิดใน …” แปลว่าติดตั้งไว้แล้ว — กดเพื่อเปิดแอปได้เลย
แอปอัปเดตยังไง

อัปเดตเองอัตโนมัติทุกครั้งที่เปิด ไม่ต้องติดตั้งใหม่ — ถ้ายังเห็นหน้าจอเก่า ให้ปิดแอปแล้วเปิดใหม่ (คอมพิวเตอร์กด Ctrl + Shift + R)

ลืมชื่อผู้ใช้ / PIN หรือเข้าไม่ได้

ติดต่อ Admin / HR ของบริษัทเพื่อรีเซ็ต — Defect Check · Site Issues · As-Built & Survey ใช้บัญชีเดียวกับ Wellcon PM · ถ้าเห็นแอปแต่ไม่เห็นโครงการ แปลว่ายังไม่ได้ถูกเพิ่มเข้าโครงการ ให้แจ้ง PM ของโครงการ

ลบแอปออกจากเครื่อง

มือถือ: กดค้างที่ไอคอน → ลบ · คอมพิวเตอร์: เปิดแอป → ⋮ มุมขวาบน → ถอนการติดตั้ง
